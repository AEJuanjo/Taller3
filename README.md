# 🔁 Taller de Ciclos en Java

---

## 📌 Descripción

>Este proyecto corresponde a un taller enfocado en el uso de ciclos en Java, donde se desarrollan ejercicios prácticos para fortalecer la lógica de programación.

>El objetivo es aplicar estructuras repetitivas, validación de datos y manejo de errores mediante un programa interactivo en consola.

---

## 📝 Instrucciones

- Crear un nuevo repositorio en GitHub
- Trabajar en grupos de 2 o 3 personas (no individual)
- Actualizar el README con la información del equipo
- Todos los integrantes deben participar en los commits

---

## 💻 Programas

### 📋 Menú principal

>El programa debe implementar un menú infinito con las siguientes opciones:

1. Suma del n-ésimo término de Fibonacci
2. Calcular el n-ésimo número primo
3. Calcular las raíces de una ecuación cuadrática
4. Calcular el promedio de n números
5. Salir

>El programa debe ejecutarse continuamente hasta que el usuario seleccione salir y debe validar entradas inválidas.

---

## ⚙️ Funcionamiento del programa

>El flujo del programa es el siguiente:

1. Se solicita al usuario la opción del menú
2. Se valida la entrada ingresada
3. Se ejecuta la operación correspondiente
4. Se muestran los resultados
5. El programa vuelve al menú principal hasta que el usuario decida salir

---

## ✨ Recomendaciones

- Validar correctamente los datos ingresados por el usuario
- Manejar excepciones para evitar errores en ejecución
- Resolver cada opción por separado antes de integrarlas
- Aplicar el principio de divide y vencerás
- Usar ASCII Art para mejorar la presentación del menú (opcional)

---

## 🎯 Ejercicios adicionales

- Crear un juego donde el usuario adivine un número aleatorio entre n y m
- Mostrar la tabla de multiplicar de un número ingresado

---

## 📊 Teoría

### 🧠 Parte 1

- Diferencia entre for, while y do-while
- ¿Qué es un ciclo infinito y cómo evitarlo?
- Anidación de ciclos en Java
- Alcance de variables dentro de un ciclo

### ⚙️ Parte 2

- Uso de break y continue
- Procesamiento de datos con ciclos
- Concepto de contador y variables de control
- Secuencias de escape

### 🛠️ Parte 3

- Atajos de teclado en VS Code
- ¿Qué es overflow?
- Personalización de la consola en Java
- Formas de crear ciclos infinitos

---

## ⚙️ Ejecución

# Compilar
javac Main.java

# Ejecutar
java Main

---

## 🛡️ Manejo de errores

>El programa debe incluir validación de datos y manejo de excepciones utilizando try-catch para evitar fallos durante la ejecución.

Ejemplo:

```java

try {
    // ejecución del programa
} catch (Exception e) {
    System.out.println("Error: entrada inválida.");
}
```
